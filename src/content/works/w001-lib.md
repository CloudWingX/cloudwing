## 项目概览

一个前后端分离的图书管理系统：读者/管理员两类角色，覆盖图书增删改查、借阅归还与分页查询。技术栈为 Spring Boot + MyBatis + MySQL 提供接口，Vue + Axios 完成页面与联调。

## 我做了什么

- **数据库设计**：设计用户、图书、借阅记录三张核心表及约束，支撑借阅状态的流转（在借/已还）与两类角色的权限隔离。
- **后端分层**：按 Controller → Service → Mapper 分层实现登录鉴权、图书 CRUD、借阅归还、分页等接口，统一做参数校验、异常处理与分页参数。
- **前端联调**：用 Vue + Axios 编写页面并调用接口，逐个解决跨域、中文乱码、时间格式等实际问题，完成功能自测。
- **工程与回归**：用 Git 做版本管理并撰写说明文档；配合测试同学专项验证，修复问题并回归。

## 沉淀与收获

完整走了一遍「需求 → 设计 → 编码 → 联调 → 回归」的闭环。第一次把分层架构真正跑通，也理解了前后端联调里那些"文档里不会写"的坑——跨域、编码、时间格式化。这个项目后来也成为我做测试用例设计与缺陷跟进时的对照对象。
