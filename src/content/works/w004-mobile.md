## 怎么定位的

不靠肉眼猜，先用无头浏览器按 **375 / 390 / 414** 三种真实机型视口 × 五个页面跑一遍，量出每页的横向溢出、页面总高、关键元素几何（这一步后来固化成 `scripts/mobile-shots.mjs`）。

量出来的问题：

- **画廊**：40 张图单列，整页 **12,726px（约 16 屏）**，翻起来非常累。
- **顶栏**：品牌 + 四个圆形按钮挤在一条 40px 高的胶囊里，品牌被压到贴边。
- **吊牌**：占着 440px 一块竖向空间，而且提示语写着「**下拉**工牌 · 开灯 / 关灯」—— 但下拉手势的判定是 `min-width: 1025px`，**手机上根本拉不动**，提示是假的。
- **首页卡片堆**：带 3D 旋转的卡片视觉外框比容器宽，右边被 `overflow: clip` 切掉约 11px。

## 改了什么

| 项目 | 改前 | 改后 |
|---|---|---|
| 画廊整页高（375 视口） | 12,726px | **4,548px** |
| 顶栏 | 品牌贴边、四个 40px 按钮 | 品牌字号/图标收小 + 允许省略号，按钮 36px，间距收紧 |
| 吊牌 | 440px + 做不到的"下拉"提示 | **点一下开关灯**，提示文案随断点切换，容器收到 400px |
| 首页卡片堆 | 右侧被切 11px | 用 `--deck-dx` 整体左移，完整落在屏内 |

另外：≤520px 隐藏 GitHub / 搜索的文字，≤400px 隐藏品牌副标题；画廊在 ≤620px 改**两列**并同步收紧卡片文案与间距。

## 顺带清理的重复信息

影集内容的 `title` 字段清一色是「2024-06-25 · MC」，而 `date` / `game` 已单独渲染，导致**同一个日期在卡片上出现两遍**。改成按「同一天同游戏」自动编号（如 `Minecraft · 03/05`），日期只出现一次；侧栏「最近更新」与更新日历里的截图条目同样处理。**没有改动任何内容文件，只改展示层。**

## 结果

三种视口 × 五个页面：**横向溢出全部 0**（15/15）。手机上侧栏是整体隐藏的（代码里 <1200px 直接 `display:none`），导航由顶栏汉堡抽屉承担。
